# advenue-web

Testovací verze webu Advenue digital, zveřejněná přes GitHub Pages.

- Web: https://radekpodrazil-maker.github.io/advenue-web/
- Zdroj: `outputs/web/advenue-digital.html` v pracovním prostoru, sem se kopíruje jako `index.html`.
- Kontaktní formulář posílá poptávky na webhook v Make.com.
- Stránka má `noindex`, aby ji Google neindexoval vedle advenue.cz.
